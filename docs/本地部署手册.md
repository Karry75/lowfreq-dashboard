# 换电看板 · 内网本地部署手册（命令级）

> 目标：在你公司内网的一台机器上把服务跑起来，同事用浏览器开内网链接即可协作（看板 + 一键同步数据库 + 多人共享跟进/备注）。
> 适用对象：会基本命令行操作即可，无需开发经验。

---

## 一、你需要准备什么

| 条件 | 说明 |
|------|------|
| 一台**常开**的内网机器 | Windows / Linux / macOS 均可。建议用**服务器 / NAS / 不关机的电脑**（笔记本下班关机服务就停）。这台机器要和同事电脑**能互访**（同内网/同网段）。 |
| Python 3.8+ | 机器上装好 Python。 |
| 能访问数据库 | 这台机器要能连你们的 MySQL(ADB)。**关键**：阿里云 ADB 有白名单，必须把这台机器的出口 IP 加入 ADB 白名单（见第四节）。 |
| 套件 zip | 从本会话下载 `lowfreq_dashboard_kit.zip`，解压到任意目录。 |

---

## 二、解压套件

把 `lowfreq_dashboard_kit.zip` 解压，得到目录（假设放 `D:\dashboard` 或 `/opt/dashboard`）：

```
dashboard/
├── dashboard.html          自包含网页看板
├── server.py               后端服务（启动看板 + 提供同步/跟进接口）
├── sync.py                 数据库抽取脚本（启动时自动调用）
├── dashboard_data.json     数据快照（启动时会自动重新生成）
├── db_conf.json            数据库连接配置（必须改！）
├── followups.json          共享跟进状态（自动生成）
├── README-部署说明.txt
└── 本地部署手册.md
```

---

## 三、安装 Python 依赖

打开命令行，进入解压目录：

```bash
# Windows
cd D:\dashboard
# Linux / macOS
cd /opt/dashboard

pip install pymysql
```

> 只依赖 `pymysql` 一个第三方包，其余都是 Python 自带库。

---

## 四、配置数据库（最重要的一步）

编辑 `db_conf.json`，填入你们数据库的账号（套件里的是示例，**部署时必须改成你自己的**）：

```json
{
  "host": "am-uf6o6wq8um88mky87167320o.ads.aliyuncs.com",
  "port": 3306,
  "user": "citybike_pro",
  "password": "你的密码",
  "database": "sharing-citybike-pro"
}
```

### ⚠️ 阿里云 ADB 白名单（连不上 90% 是这里）
1. 登录阿里云 ADB 控制台 → **数据安全 → 白名单设置**。
2. 把**这台部署机器的出口公网 IP** 加进白名单（公司内网通常是一个统一出口 IP，找网管确认）。
3. 如果 ADB 有**内网 endpoint**（同 VPC），把 `host` 改成内网地址，速度更快且不受公网白名单限制。
4. 验证连通：这台机器上 `telnet <host> 3306` 能通，说明网络 OK。

---

## 五、启动服务

```bash
python server.py
```

看到类似输出即成功：

```
🔄 启动中自动同步数据库…
✅ 启动同步完成
✅ 看板服务已启动: http://0.0.0.0:8080/  (目录 ...)
```

> **启动时自动连库同步一次**：每次启动拿到的就是最新数据。若数据库连不上，会打印警告并降级用已有快照，服务照常启动（不会崩）。

## 六、本机验证

浏览器打开：

```
http://localhost:8080/
```

能看到看板 = 服务 OK。右上角「🔄 一键同步数据库」按钮可随时手动重抽。

## 七、查这台机器的内网 IP

同事要访问，需要这台机器的**内网 IP**：

```bash
# Windows
ipconfig
# 找「IPv4 地址」，如 192.168.1.50

# Linux
hostname -I
# 或 ip addr

# macOS
ifconfig | grep inet
```

记下这个内网 IP（如 `192.168.1.50`）。

---

## 八、防火墙放行 8080 端口

同事才能连进来：

**Windows**：
- 控制面板 → 系统和安全 → Windows Defender 防火墙 → 高级设置 → 入站规则 → 新建规则 → 端口 → TCP → 特定本地端口 `8080` → 允许连接 → 全勾 → 命名「dashboard-8080」。

**Linux**：
```bash
sudo ufw allow 8080/tcp
# 或 CentOS: sudo firewall-cmd --permanent --add-port=8080/tcp && sudo firewall-cmd --reload
```

**macOS**：系统设置 → 网络 → 防火墙 → 选项 → 允许入站。

（把 `192.168.1.50` 换成你第七步查到的内网 IP）

## 十、协作功能怎么用

| 功能 | 怎么用 |
|------|--------|
| **一键同步数据库** | 看板右上角按钮 → 重连库刷新全量数据（约 2 秒），页面自动重载。 |
| **多人共享跟进** | 明细表「用户跟进 / 协议跟进」列、催收清单「用户跟进」列，点 ✎ 填**跟进人 + 状态 + 备注**，保存即写入后端。所有同事打开同一链接看到彼此记录。 |
| **操作人追溯** | 右上角先填「我的名字」，便于知道谁分配的。 |
| **跟进筛选** | 明细查询页可按「跟进状态」筛选（未分配/待跟进/跟进中/已转化·已结清）。 |

## 十一、让服务常开（后台运行）

**Windows（开机自启、关窗口不退出）**：
- 用 `pythonw server.py`（无控制台窗口）；
- 或用「任务计划程序」建一个开机触发、运行 `python server.py` 的任务。

**Linux / macOS**：
```bash
nohup python server.py > server.log 2>&1 &
# 查看日志：tail -f server.log
# 停止：找到进程号 kill <PID>  （ps aux | grep server.py）
```

---

## 十二、打不开？排查清单（按顺序）

| 现象 | 原因 | 解决 |
|------|------|------|
| 本机 `localhost:8080` 也打不开 | 服务没起 / 端口占用 | 回看第五步启动日志；换端口改 `server.py` 第 12 行 `PORT` |
| 本机能开，同事打不开 | 不在同内网 / 防火墙 | 同事 `ping 192.168.1.50`；检查第八步防火墙；确认同网段 |
| 看板打开但数据是旧的 / 同步报错 | 数据库白名单 / 密码 | 见第四节；本机 `telnet <host> 3306` 验证 |
| 同步按钮转圈失败 | 机器不能出公网 | 确认部署机能访问 ADB；或改用 ADB 内网 endpoint |
| 同事打开空白 | 跨网段路由 | 让同事连同一 WiFi/内网；或部署机做端口映射 |

---

## 十三、后续更新数据

- **自动**：每次 `python server.py` 启动即同步最新。
- **手动**：看板右上角「🔄 一键同步数据库」。
- **命令行**：部署机上 `python sync.py`。

---

## 安全提醒

- `db_conf.json` 含数据库明文密码，勿外发、勿上传公网仓库。
- 看板已脱敏手机号，但仍含协议金额、欠租名单、用户姓名等业务数据，内网分享注意接收范围。
- 建议把 8080 端口仅对**公司内网**开放，不要映射到公网。

## 附录：一键启动脚本（免去手动敲命令）

套件已附带脚本，按你的系统选一个：

**Windows —— 双击 `start.bat` 即可**
脚本自动完成：检查 Python → 安装 pymysql → 启动服务（含自动同步数据库）。
前提：先编辑好 `db_conf.json`，且本机已加入 ADB 白名单。关闭窗口即停服务。

**Linux / 服务器 —— 注册为常开系统服务**
1. 把 `dashboard.service` 放到 `/etc/systemd/system/`，把里面 `WorkingDirectory` / `ExecStart` / `User` 改成你的路径和用户。
2. 执行：
   ```bash
   sudo systemctl daemon-reload
   sudo systemctl enable --now dashboard
   journalctl -u dashboard -f   # 查看日志
   ```
   服务会开机自启、崩溃自动重启，最适合做长期固定的内网链接。

**启动前自检数据库（可选但推荐）**
```bash
python check_db.py
```
连通常会显示协议数；不通会提示检查白名单/密码/网络——先解决这个再启动，避免空跑服务。
