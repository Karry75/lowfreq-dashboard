【第一次使用：只需 2 步】
  1. 确认本机已装 Python 3.8+（没装去 https://www.python.org/downloads/，
     安装时务必勾选 "Add Python to PATH"）。
     如果没装 Python，脚本会提示你去下载，不会报错退出。
  2. 双击 fix_and_sync.bat → 自动检测 Python → 自动装依赖 → 自动判断公网/内网 →
     自动测试数据库 → 自动连库出看板 → 自动启动本地服务 → 自动用浏览器打开。
     （如果同步过程中报错，会自动把完整错误日志写入 out/fix_and_sync.log 并打开记事本）

【日常使用：3 种方式】
  方式 A（推荐，最简单）：
    每天到公司后双击 fix_and_sync.bat，它会先诊断环境、自动修复常见问题，
    然后同步并启动服务、打开看板。如果失败，会打开日志告诉你原因。
  方式 B（浏览器内随时刷新）：
    双击 run_sync.bat 启动本地服务 → 浏览器自动打开 http://127.0.0.1:8173 →
    点击右上角「🔄 同步数据库」按钮即可刷新，无需再双击任何脚本。
  方式 C（完全无人值守）：
    右键“以管理员身份运行” setup_auto_sync.bat → 注册成功后，
    Windows 每天 08:30 自动后台同步，你只需打开浏览器看结果。

【如果同步按钮是灰色 / 回访排班没数据】
  原因：你当前打开的是本地 HTML 文件（地址栏 file:// 开头），
        而不是通过本地服务打开的页面（地址栏 http://127.0.0.1:8173）。
  解决：关闭当前页，双击 fix_and_sync.bat 或 run_sync.bat，
        让脚本自动用 http://127.0.0.1:8173 打开看板。

【全自动更新程序本身（可选）】
  当功能升级时，双击 update.bat：
    · 若项目是 git 仓库，自动 git pull，无压缩包；
    · 否则自动下载最新 zip → 自动解压覆盖 → 自动保留你的 out/ 和 uploads_sms/ 数据。
  你不需要手动下载、解压、复制粘贴。

【公网 vs 内网数据库】
  db_conf.json 里默认是公网 host。如果在公司内网且 ADB 给了内网地址：
    1) 用记事本打开 db_conf.json；
    2) 在 intranet_host 字段填入内网地址，保存；
    3) 以后双击 auto_sync.bat 或 run_sync.bat 会自动优先测内网，通则走内网，
       内网不通自动 fallback 到公网，无需你手动切换。
  若只想强制走内网，可双击运行（或定时任务改为）：
       python sync_intranet.py

【短信 Excel 更新】
  若阿里云又导出新的短信记录，把文件改名为 export1.xlsx / export2.xlsx
  放进 uploads_sms/ 目录（覆盖旧的），再双击 auto_sync.bat 或点“同步数据库”。

【放在 C 盘还是 D 盘？】
  都可以。所有脚本都用"自身所在目录"计算路径（相对路径），
  所以放 C 盘、D 盘、U 盘都行，文件夹也能随便改名。
  唯一建议：路径里尽量别带中文和空格，最稳。

【回访排班 Tab（手动生成回访名单 + 三级标签）】
  v10.12 起：每次同步不再自动分配接待任务。需在「回访排班」Tab 手动操作：
   ① 接待人员与规则配置：名单（默认8人，可增删）、每人每日上限（默认30）、
      未接通再次回访间隔（默认3天）。改完点"保存配置"即生效。
   ② 生成名单筛选：选【接待人员】、【接待数量】、【电池产品】、【代理商】等筛选条件，
      点【生成回访名单】按钮→ 系统从低频用户名单抽取符合条件的人数分配给选定接待人。
   ③ 回访调度：状态为"待回访"的任务，含因"未接通"自动生成的 +N 天再次回访。
   ④ 排班总览：全部任务，可按接待人/状态/手机号筛选；点"编辑"打开标签弹窗。
  贴标签：点任意"贴标签/编辑"→ 弹窗内分 一级/二级/三级/回访结果 勾选。
      保存时若勾选了未接通类结果（外呼未接通/未接听/联系不上/空号/停机/
      非本人接听/表明身份挂机），系统自动为该用户生成 +N 天的再次回访任务。
  所有排班结果存在 out/assignments.json（本机文件，不回写生产库）。

【内网访问（同事共用同一份数据）】
  本服务监听所有网卡(0.0.0.0:8173)。把本机作为"中枢机"：
    - 中枢机双击 run_sync.bat 启动服务（黑色窗口常驻，建议用任务计划每日自动同步）。
    - 同事在内网其他电脑的浏览器直接打开 http://<中枢机内网IP>:8173
      即可看到同一份看板与排班，零部署（无需装 Python）。
    - 同事也可以直接点看板右上角「🔄 同步数据库」刷新（相当于在中枢机触发同步）。
    - 注意：中枢机需放行防火墙 8173 端口入站；中枢机若休眠/关机，同事将无法访问。
  若只想自己用，本机访问 http://127.0.0.1:8173 即可，无需任何额外配置。

【常见问题】
  Q: 提示连接数据库失败 (2013/超时)？
  A: ① 本机是否已连公司内网/VPN（若使用内网地址）；② 本机出口 IP 没在 ADB 白名单。
     登录阿里云 ADB 把本机 IP 加进白名单即可（看板连不上最可能是 IP 白名单问题）。
  Q: 没有短信 Excel 也能跑吗？
  A: 能。没有 uploads_sms/ 下的文件时，脚本会跳过短信合并，仅生成不含
     短信结果列的看板（看板里"发送结果/失败原因/接收时间"列会为空）。
  Q: 看板支持哪些筛选？
  A: 顶部支持省份/城市/区域/街道/电池产品/协议状态/是否低频/低频档位/
     操作类型/是否流通/发送结果/使用天数/协议ID/关键词/回访标签等筛选。
     其中「使用天数」支持多选、全选、反选。
  Q: 改名了文件夹还能跑吗？
  A: 可以。所有路径都按"脚本所在目录"自动计算，文件夹随便改名、随便放。
  Q: 双击 run_sync.bat 后顶部出现乱码报错？
  A: 新版 bat 文件已改为纯 ASCII（不含任何中文），所有中文提示由 Python
     脚本输出，彻底避免 CMD 编码/代码页不一致导致的乱码。
  Q: 回访排班里"今日待分配"是空的？
  A: 低频用户首次同步时才会被自动分配；已分配过的不会重复出现。若想重新分配，
     删掉 out/baseline.json（清基线）后再双击 auto_sync.bat 即可。
  Q: 同事打不开 http://<中枢机IP>:8173 ？
  A: ① 中枢机是否开着 run_sync.bat（黑窗口在）；② 中枢机防火墙是否放行 8173
     入站；③ 同事与中枢机是否在同一内网。检查后让中枢机重启 run_sync.bat 重试。

【访问权限（v10.28.5 新增：账号密码登录 + 角色 + 手机白名单 + 模块）】
  本看板现在支持"不同的人用不同账号登录、看不同的内容、没授权的人打不开"：
  · 账号密码登录：打开看板先到登录页，输入「账号+密码」才能进。密码以哈希（sha256+随机盐）
    存储，配置文件中不含明文密码。旧版 ?user=boss 明文链接已作废（任何人都能伪造，已停用）。
  · 角色：创建账号时选「角色」（管理员/客服主管/客服/财务/排班专员/自定义）即一键配好对应模块，
    仍可手动微调每个模块的勾选。
  · 模块权限：可见的功能页（回访看板/回访排班/排班总览/历史排班/全部活跃协议/欠租催收/低频用户等），
    并可勾选「可同步数据库」（共享模式下也能点「同步数据库」）。
  · 数据范围（按城市）：给账号填"数据范围"——城市关键词（逗号分隔，如 上海,杭州），
    留空或填"全部"表示不限；受限账号只能看到定位城市命中的客户。
  · 手机白名单：给账号填"手机白名单"——手机号前缀（逗号分隔，如 138,1390010），
    留空或填"全部"表示不限；与"数据范围"取「与」关系（城市命中 且 手机号前缀命中才显示）。
  · 免登录链接：在「人员权限」里仍能点「复制免登录链接」生成 ?token= 链接，对方免登录直接进；
    也可让其用账号密码登录。

  默认管理员账号（首次使用请尽快改密码）：
    账号 admin  密码 admin123
  默认同事账号（演示用，可自行删改）：
    老板 boss / boss123（全部权限）｜ 客服小王 wang / wang123（仅回访看板，限上海杭州南京）
    ｜ 财务小李 li / li123（仅排班总览+历史排班）
  修改方式：用管理员账号登录 → 右上角「人员权限」→ 增删账号、改密码、设角色/模块/范围/白名单 → 保存。
