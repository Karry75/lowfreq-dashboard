低频用户 · 欠租催收智能回访看板

一款面向换电 / 两轮出行行业的数据分析与运营看板：自动识别低频用户与欠租风险， 构建用户画像、归属地、促成漏斗，并生成可按接待人 / 标签筛选、按日 / 周 / 月统计的运营看板， 以及可直接下发的智能回访排班。纯 Python + 原生 HTML，零前端框架、零构建。

真实业务分布

内置 2600 条脱敏协议数据，保留真实的状态分布、城市分布、促成漏斗与回访排班。

手机号归属地

数据自带 → 离线字典 642 条 → 在线 API 三级兜底，断网也显示。

列式编码优化

看板 HTML 仅 ~750KB（gzip 144KB），12 万行解码 < 1s。

隐私合规

手机号掩码、员工匿名、街道/社区清空；数据库凭证永不入库。

隐私说明：本仓库所有数据均经 desensitize_data.py 脱敏处理——手机号变为 186****1001、员工 / 接待人姓名变为 员工#NN、街道 / 社区清空（仅保留省 / 市 / 区用于聚合）。 数据库账号、密码、token 等凭证从不提交（见 .gitignore），仅提供 db_conf.example.json 占位。本地连真实库时请填写你自己的 db_conf.json 且不要推送到公开仓库。
